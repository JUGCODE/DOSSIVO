# DOSSIVO 证据呈现 Protocol

draft-0.1 · 2026-11-05 · 应用映射草案，非通用PACI正式规范。

PACI Protocol / PACI-DOSSIVO-FL：等待权威文字与实际链上部署交付、验证。没有合约地址或部署交易可据实展示。当前不能声称完全对应已发布的通用规范，正式链上卡发布关闭。

## 1. 范围与六式框架

DOSSIVO 是业务应用，通过 PACIscan 使用 PACI 通用协议；不分叉通用内核。六式框架承接业务借贷记录、链上时间与共识、AI Ledger 和 Jurisdiction Ledger。框架叙事不代表这些链上能力已部署。PACIscan 保留 Record / Explore / Verify / Challenge。

## 2. 固定来源与企业确认

任务明确主体、工厂、期间、请求与目的。字段绑定材料版本、原文位置、原值与单位、转换方法和确认历史。更正追加新版本及理由，不能覆盖原提取值；企业确认不升级来源独立性。只有目录的资料不标为已阅读原件。

## 3. 检查、领域规则与结果

PACI-FLR 独立版本管理领域公式与规则。本次用户要求的 PACI-DOSSIVO-FL 名称作为证据呈现层标题保留，是否等同于 PACI-FLR 或引用它，待 Protocol 窗口冻结对应关系。H/P 初始阈值、示例价格和测试数量不视为正式政策。材料忠实性、来源认证、独立性、现实佐证和法律分析分别陈述。

## 4. 未解决事项与挑战

open、explained、remediating、resolved 保留各自含义。待审解释及整改中不是已解决。资料不足和已知问题同时显示。企业拒签不能阻止有权限的挑战、回应或更正；无合格独立复核人时不输出独立裁决。

## 5. 私密、交付与版本

默认 PRIVATE。Link1 摘要和 Link2 原件分别按接收人、版本、用途、页范围及期限授权，每次查询和导出重新鉴权。签核快照不被最新内容覆盖，新版本不自动扩大旧授权。敏感原件不上公开链。当前新任务模块仅支持合成材料与目录，不接受真实劳工原件。

## 6. 签核与链上执行

正式卡必须绑定有权人签核、原件与卡片承诺、精确版本、PACI 回执、对应 Protocol 合约执行事件及最终性验证。仅哈希一致、登记回执、代码开源、普通地址或 CA 结果哈希均不能代替这一链条。升级追加新版本；代理合约必须披露实现和管理权限。
