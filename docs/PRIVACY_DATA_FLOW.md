# 本轮数据路径与隐私边界

| 路径 | 实际行为 | 尚未承诺 |
|---|---|---|
| 浏览器输入 | 新私密任务登录后仅合成场景/目录元数据、确认、事项 | 不接受真实工人/银行/合同资料；无自动预上传脱敏 |
| DOSSIVO服务 | Sites身份做所有者边界；受控JSON参数化SQL | 账号不是完整组织RBAC或法代身份认证 |
| D1 | 合成原文、字段、历史快照、操作与队列持久化 | 不宣称CN物理驻留、客户持钥或平台不可读 |
| 解析器 | 后端固定样本regex，无网络/模型/工具执行 | 不称OCR、AI语义提取或准确率已评估 |
| PACI请求 | 仅显式配置并点击同步时发送固定合成准备件 | 生产配置为空；无静默海外模型fallback |
| PACI响应 | 固定摘要/身份范围检查，回执本地保存 | 无通用链上证明、独立见证或公开签名回执 |
| 导出 | 当前身份鉴权；合成全文私密JSON | 不是多买家页级披露，不能当公开链接 |
| 日志/缓存 | API private,no-store；错误采用安全代码 | 未完成全面运维日志/备份/保留/恢复/删除审计 |
| 公开Protocol页 | 规范映射、公开状态、无私密原文 | 不公开合约地址占位符、不把钱包冒称协议 |

跨账号、CAS与SQLite重启权限逻辑已测试；浏览器/生产范围见验收报告。真实敏感材料、Link2、投诉身份、专业复核、备份恢复和区域路径均尚未放行。任务无用户上传文件入口，无模型服务配置，不会因文档含指令改变权限或对外发送。

新增基本授权：只把企业选定的固定最小投影保存到basic_grants，128位随机码只存摘要，兑换绑定一个登录actor。查看/下载在最终输出前事务重验并记访问事件；代码不在URL中，响应no-store。上传仅合成UTF8文字，仍不接收真实个人或企业秘密。历史已下载副本不能撤回，在线到期只停未来访问。无原件/全文/OCR披露。
