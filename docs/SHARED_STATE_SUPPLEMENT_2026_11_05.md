# DOSSIVO 共享状态与证据复用补充要求

日期：2026-11-05。性质：本轮开发补充与决定记录，不替换原宪章、PACI 通用协议或领域规则。依据附件分析、评估表、官方文章与当前源码核查；实施和验收结果仍以本轮状态、测试报告及 HANDOFF 为准。

## 判断与来源边界

DOSSIVO 应积累的是能够按权限复用、保留历史和解释变化的证据关系，以及企业与接收方实际协作的记录。只有多个实际参与者持续使用这些记录并减少重复工作后，才能讨论已形成的网络效应。合成演示、数据库表、链上地址和主观评分均不能证明市场护城河已经成立。

a16z Frontier 官方页面《Reusable networks》署名 Daren Matsuoka，日期为 2026-11-03。附件英文材料和转发文字标注 Nov 4；是否为邮件转发日期未独立核实。该文章提出网络和共享历史的重要性，属于战略观点，不是对 DOSSIVO 产品、市场或法规适用的验证。

Claude 关于连续历史和多接收方复用的方向值得采用，但三点应纠正：第一，现有设计不等于签核、链上锚定或真实买方使用已经完成；第二，不能把供应商自有资料或复用称为独占能力；第三，新增数据只有在授权、独立性、可比性和校准成立时，才可能改善同行判断。

IntegrityNext 官方帮助页已说明可向新的邀请客户共享现有已完成档案，并提供档案 URL 与 ID。TrusTrace 官方平台页明确介绍统一数据基础和资料复用。因此“同一供应商必然向十个买方填十遍、竞品都是不能复用的数据孤岛”的笼统判断不成立。官方页面也不能证明其所有权限细节或实际客户体验；本轮未做竞品产品实测。

附件评估表中五项“当前”均为人工填写的 0。这表示作者当时的主观评估或未测量状态，不是从生产数据计算的当前结果；不得据此宣布真实用户、买方或收入一定为零，也不得用人工改分充当增长证据。

## 本轮采纳并实施的范围

在现有合成材料流程中，向出口企业所有者展示授权生命周期及版本级复用使用记录。以现有 `dossivo_basic_grants`、`dossivo_access_events` 和真实保存事件为基础，不生成假买方或回填历史事件。本轮已实现所有者统计接口、折叠面板及新投影的固定卡标识；108项自动化测试、TypeScript及Worker构建通过。本地浏览器只核对匿名入口的登录保护，未宣称生产多账号闭环已通过。新投影中的source_card_id仅用于对应同一固定卡；旧投影不重写，卡标识不代替链上或独立证明。

核心对象是“同一任务中的同一固定卡片版本”。不同参数选择、不同有效期及不同接收账号使用各自授权，不能共享一份可任意转交的权限。该功能衡量同一版本的受控使用，不代表跨任务资料复用、跨企业网络或独立认证已经完成。

| 指标或记录 | 精确定义 | 不得解释为 |
| --- | --- | --- |
| 已生成授权 | 该任务/固定卡成功保存的不同授权ID数量 | 已有同样数量买方或业务需求 |
| 已兑换授权 | 首次成功绑定接收账号的不同授权数量 | 买方接受证据或公司身份已核验 |
| 不同阅读账号 | 同一固定卡的成功授权使用中，对非所有者接收账号去重；同一账号多码只计一次 | 不同企业数量、采购人数或已确认买方数量 |
| 同一版本多账号使用 | 同一固定卡被两个或以上不同接收账号按独立授权使用 | 事实被多家独立核实、获得采购批准 |
| 查看次数 | 通过当前权限检查并成功记录的 VIEWED 请求事件数量 | 人实际阅读、理解、接受或停留时长 |
| 下载次数 | 通过当前权限检查并成功记录的 DOWNLOADED 请求事件数量 | 文件已保存到本地、打印或实际用于采购 |
| 最近使用 | 成功查看/下载事件中的最近服务器记录时间 | 当事人最后一次阅读离线副本的时间 |
| 到期和撤销 | 当前授权状态，与历史使用记录分别展示 | 撤回已合法取得的离线副本，或抹去过去使用 |

统计保留到期或撤销之前已发生的成功使用，历史不因撤权清零；当前有效授权数另算。未通过鉴权、格式错误、过期/撤销拒绝、失败兑换和限流尝试，不计入成功使用。刷新或重试可能产生多次成功请求，所以请求数不当作独立用户数。当前状态变化与历史事件也不能合成一个“全部通过”状态。

所有统计必须由服务端在所有者与任务权限内从完整记录计算，不能仅对前端当前100条列表计数并冒称全量。所有者只能看自己任务的记录。买方不得由此看到其他买方的授权、订单、批注、价格、账号或上游关系。

面向用户的统计与时间线不展示接收方账号ID、邮箱、真实姓名、IP、授权码明文或其他个人标识；账号去重仅在已有受控身份字段上由服务端内部计算，不为该指标新增个人资料收集。不得公开全网榜单、声誉分或反推企业关系的汇总接口。

## 下一阶段优先落实

1. **稳定主体和来源引用**：企业、法人及工厂分开标识；登记信息与代表资格分别记录。相似名称只给候选，不自动合并。重复导入、摘录、翻译和同源派生保留共同来源；导入已有材料不制造新的独立佐证。新任务引用既有版本并重新确认期间、范围和用途。
2. **受影响任务与更正提示**：建立哪些任务或授权引用哪个版本的关系。新更正、挑战、撤回和规则变化产生可审阅影响列表；只向仍获授权的接收方提示必要状态，不自动披露新正文，也不覆盖旧交付。
3. **买方明确回应**：作为新增建议，另行设计“已收到”“请求补件”“接受本次提交”的明确操作、主体与时间、适用版本和撤回/更正路径。默认未知；接受某次提交不等于法律合规、事实核实或采购承诺。本轮未实现。
4. **验证真实签核与链上历史**：企业认证、代表权限、CA签名、PACI登记及Protocol链上执行逐项验证，不能相互代替。材料覆盖期间、上传/取得时间、冻结时间、PACI登记时间与链上纳入/最终性时间分别保存；今天导入18个月历史材料不能写成已经连续锚定18个月，也不能由链上时间证明材料中的事实发生时间。
5. **开展可测量试点**：先完成登录后出口企业与两个接收账号的浏览器验收，再在合规数据条件具备后开展真实试点。测量第二请求有效复用、实际人工纠正、补件往返与相同质量下的操作时间。济南光辉、恒立、Biancalani等在附件中出现的名称仅为候选或背景；本轮未核实参与、合同、付费、数据授权或买方承诺，不对外宣布合作。
6. **校准同行队列**：行业、产品、场所、期间、自动化、财务和人数口径可比且授权有效后，才评估样本与分位；多个月不能充作多家独立企业。记录偏差、误报、漏报和未知，数据增加不自动等于判断更准。

以上延续主指令D1→D2→D3→D4→D5→D6的阶段依赖；本轮增量只是为现有基本授权提供真实、有限的使用测量，不据此宣称D4全部通过。真实敏感原件、生产身份、独立裁决、正式卡和链上能力继续按原门槛放行。

## 产品和商业表达

可将长期方向解释为“企业掌控的可复用证据协作层”，同时以当前任务的真实效果服务客户。收费应对应可交付的整理、复核协作和回应能力；不因网络叙事推迟可验收的业务闭环，也不承诺保住订单、欧盟认证或监管接受。

可读导出、结构化清单、清晰权限和版本解释应继续可用。已合法导出的历史资料在停止订阅后仍能阅读；客户可以退出，不以数据锁定或无法迁移制造壁垒。开放协议与商业服务分别说明，公开规则不等于公开客户材料或开放商用源码许可。
