# Dossivo Product Constitution Repository Baseline

Current product reference: `DOSSIVO 产品与证据协作宪章 v3.0`, dated 2026-10-26. The 2026-09-18 v2.0 remains the historical baseline of the first synthetic workflow.

This work package implements Chapter 31's first synthetic closed loop. The governing decisions are: sell verifiable outcomes rather than seats; evidence precedes scores; deterministic code controls permissions, versions, counting and money; enterprise facts and external disclosure require human confirmation; Link 1 never exposes originals; professional matching must not invent credentials or allow payment to change suitability ranking; and unverified regions must reject real originals.

The supplied constitution remains the product reference. This repository note is an implementation index, not a statement of formal legal adoption.
