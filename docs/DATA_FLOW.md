# Data Flow

The browser sends questionnaire answers and actions to same-origin APIs. The server derives synthetic facts, findings, cards and candidates, then persists case state, workflow steps and agent runs in D1. Link 1 stores recipient, expiry, views, case reference and card version. Its API returns card fields and scope only.

No real original, OCR text, vector, model prompt, third-party API or cross-region transfer exists in WP1.
