- 本轮新增≤10KB UTF-8合成TXT上传/粘贴，类别和源场所/月明确；真实企业账单、PDF/OCR、真实敏感材料处理及模型调用未启用。不得把合成文字解析称AI提取已经完成。
- `/eu-buyer`独立入口，必须先使用现有Sites身份注册/登录，再兑换代码。不创建公开企业材料目录，不把登录者当作国籍/地域或企业资格已认证。
- 基本授权只包含固定卡的企业/场所/月、覆盖度、未解决事项数量，加上企业逐项勾选的材料状态和数值。无原件、完整文字、OCR、文件路径、保管人、内部说明、工人身份、买方订单或价格。
- 企业生成代码时选择48或72小时，期限从生成时起算。代码128位随机，仅保存规范化代码的SHA-256；代码只在生成成功的响应中展示一次，不放URL或持久明文。若原回执丢失，同键恢复只回原授权，不重新泄露代码，企业可撤销后另发。
- 第一个成功兑换的登录账号绑定授权；代码不能再给另一个账号兑换。同一幂等操作重试恢复原结果，但仍核对当前授权。每账号15分钟最多10次兑换尝试。
