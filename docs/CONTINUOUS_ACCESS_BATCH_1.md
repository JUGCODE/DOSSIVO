## 实际范围

- 新UI默认提供CONTINUOUS_SUMMARY，另可显式选择TEMPORARY。
- 持续摘要的48/72小时仅为首次兑换窗口，兑换绑定单一账号；后续普通查阅不设业务次数或固定到期日，可由所有者撤销。
- 旧API未传access_mode默认TEMPORARY，迁移旧记录默认TEMPORARY；旧期限和旧幂等摘要不变。不会追溯延长历史授权。
- 持续摘要服务端拒绝任何精确数值选择。只共享已有基本投影中的主体/场所/期间、材料覆盖、所选材料状态、固定卡事项汇总；不含原件、字段原文、私密投诉、价格或其他买家资料。
- 仅支持固定版本和COMPLIANCE_REVIEW用途；FOLLOW及其他用途拒绝，而不是静默接受。新版本、新字段或用途需要新授权。
- 持续摘要发生任务后续变更时显示UPDATE_REVIEW_REQUIRED；固定卡及红色事项不覆盖。当前保守地将任何后续任务变更提示待复核，不推断所有变化都是不利证据。内部新事项正文和新计数不进入持续投影。临时授权保留其历史最小状态计数契约。
- 每次查看、下载以及重试重新鉴权，日志提交前原子检查撤销。HTML下载保持历史可读，标明持续可撤销及复核状态，不是可实时更新的离线证明。
- 统计active_grants：已兑换持续授权在代码过期后仍有效；未兑换且已过期的代码不算有效。
- 首页和侧栏中文统一“欧盟用户入口”，功能仍位于私密任务内，保持首屏简洁。
